BIZCON DIGITAL INVITATION — SETUP

1. Extract the ZIP file.
2. Open the folder and double-click index.html.
3. The two logo crops from your supplied invitation poster are already in assets/:
   - assets/university-logo.png
   - assets/bizcon-logo.png
   Replace either file with a better-quality transparent PNG if you have one.
   Keep the same filenames, or update the image src values in index.html.
4. Add your licensed/royalty-free instrumental audio file to this folder and name it:
   invitation-music.mp3
   Music starts only after the visitor presses the MUSIC button.
5. Internet is required for Google Fonts and the GSAP CDN. The invitation still has
   basic CSS/JavaScript animations if GSAP cannot load.
6. To share it online, upload the extracted folder to a static hosting service
   (for example GitHub Pages or Netlify). Opening index.html locally works too.

EDITING THE INVITATION
- All visible invitation wording is in index.html.
- Styling is in style.css.
- Interactions and animations are in script.js.
